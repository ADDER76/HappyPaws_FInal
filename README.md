# HAPPYPaws_FINAL

HAPPYPaws_FINAL es una aplicación web enfocada en la gestión y adopción de mascotas. El proyecto ofrece una interfaz sencilla para que refugios y usuarios puedan interactuar con la plataforma.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- SQLite

## Estructura del proyecto
```
HAPPYPaws_FINAL/
├── frontend/
│   ├── html/
│   │   ├── index.html
│   │   ├── login_usuario.html
│   │   ├── refugio.html
│   │   └── usuario.html
│   ├── css/
│   │   ├── style.css
│   │   ├── style_refugio.css
│   │   ├── styles.css
│   │   └── usuario.css
│   └── js/
│       ├── menu.js
│       ├── refugio.js
│       ├── script.js
│       └── usuario.js
├── backend/
│   └── db/
│       ├── schema.sql
│       └── seed.sql
├── .gitignore
├── makefile
└── README.md
```

## Cómo ejecutar
1. Abrir el frontend desde `frontend/html/index.html` en un navegador web.
2. Para el backend, utilizar la base de datos SQLite ubicada en `backend/db/`. Inicializar la conexión o servidor correspondiente según las necesidades del proyecto.
